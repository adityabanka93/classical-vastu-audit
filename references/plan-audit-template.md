# Floor plan audit worksheet

## User-supplied inputs

- Building type: [plot / house / apartment / shop / other]
- Assessed boundary: [plot / actual building / apartment unit]
- Floor: [level]
- Source of north direction: [survey / trusted map / compass / unknown]
- Plot and room dimensions: [measured / approximate / missing]
- Which entrance: [compound gate / building lobby / dwelling unit]
- Door aperture and location: [draw on plan, do not guess]
- Special geometry: [recesses / angular walls / multiple entrances]
- Consultant's exact claim: [quote]
- Proposed treatment and charges: [optional]

## Analysis

1. Establish actual north; never presume the plan's top points north.
2. Identify the wall, frame, and context that the classical passage actually describes.
3. Select and cite the classical chapter and edition **before** applying a grid.
4. Distinguish an eight-position side scheme from nine-way or other divisions; do not mix them.
5. Measure the center of the actual doorway aperture against a correctly reconstructed plan.
6. Note uncertainty due to irregular shape, unmeasured length, doorway straddling a gridline, or differing textual readings.
7. Compare each claimed rule with its own passage and scope. Report disagreements among texts.
8. Evaluate expensive remedies independently; do not treat metaphysical effects as demonstrated.
