# Contributing

Contributions that improve **source accuracy** are welcome: corrections to editions and verse numbers, links to original Sanskrit and reputable translations, edition comparisons, and well-documented test cases using **fictional** floor plans.

Please include:

1. Primary work, edition, editor/translator, chapter and verse (and stable URL or bibliographic citation).
2. Exact issue being fixed and whether it affects a proposed geometry calculation.
3. Distinction between textual prescription, modern interpretation and objective evidence.
4. Permission/copyright status of any quoted passage or diagram.

**Please do not contribute**: copied scans/modern translations without permission, personal floor plans or house addresses, medical/financial predictions, universal 'doomsday' claims, or sponsored remedies presented as evidence.

Open an issue for textual ambiguities; prefer an explicit `UNDETERMINED` result over false precision.
